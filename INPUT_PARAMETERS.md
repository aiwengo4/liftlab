# Каталог входных параметров

Нормативный каталог формы LiftLab. Фактические диапазоны проверяются в `src/scenarioForm.ts`; при расхождении код и тесты имеют приоритет.

## Здание и сотрудники

| Параметр | По умолчанию | Допустимо | Назначение |
|---|---:|---:|---|
| Надземные этажи | 7 | 2–100, целое | Этажность здания |
| Сотрудники всего | 0 | 1–10 000 для запуска | Общая численность |
| Сотрудники на этаже | 0 | 0–10 000, целое | Сумма должна совпадать с общей численностью |
| Распределение | вручную | вручную / поровну | При равномерном режиме первый этаж по умолчанию исключён |
| Этаж столовой | 1 | существующий надземный этаж | Цель обеденных маршрутов |

Нулевое число на этаже означает, что сотрудников компании там нет. Отдельного признака аренды не используется.

## Подземная парковка сотрудников

| Параметр | По умолчанию | Допустимо | Назначение |
|---|---:|---:|---|
| Паркинг включён | нет | да / нет | Добавляет подземные точки начала и окончания дня |
| Подземные этажи | 1 | 1–4, целое | Обозначаются `−1…−4`; этажа 0 нет |
| Доля сотрудников | 0% | 0–100% | Утром начинают путь с паркинга, вечером возвращаются туда же |

Сотрудники выбираются воспроизводимо и распределяются между включёнными этажами максимально равномерно. Каждый используемый подземный этаж должен обслуживаться хотя бы одним лифтом.

## Лифты

| Параметр | По умолчанию | Допустимо |
|---|---:|---:|
| Количество лифтов | 2 | 1–20, целое |
| Вместимость | 6 человек | 1–40, целое |
| Время между соседними этажами | 4 с | 0,5–30 с, шаг 0,1 |
| Разгон и торможение суммарно | 2 с | 0–30 с, шаг 0,1 |
| Открытие и закрытие дверей | 1 с | 0–30 с, шаг 0,1 |
| Выдержка с открытыми дверями | 2 с | 0–60 с, шаг 0,1 |
| Посадка или высадка человека | 0,2 с | 0–5 с, шаг 0,1 |
| Начальный этаж каждой кабины | 1 | существующий этаж из остановок этой кабины |

Одно поле дверей применяется отдельно к открытию и отдельно к закрытию. Технические параметры общие для группы, начальный этаж и остановки задаются отдельно каждому лифту.

Для каждого лифта:

- первый и начальный этажи обязательны;
- список непустой, уникальный и по умолчанию содержит все доступные этажи;
- остальные остановки можно включать и выключать;
- доступны пресеты «Все этажи» и «Через этаж от 1-го»;
- вызов назначается только кабине, обслуживающей этаж посадки и назначения;
- при отсутствии прямой пары модель выбирает одну подходящую кабину и добавляет обязательный участок по лестнице; пересадки не моделируются.

Стратегии диспетчеризации: глобальный FIFO (по умолчанию), ближайший вызов и гибридная стратегия с FIFO-приоритетом после 120 секунд.

Физические кнопки вызова в текущей модели всегда разделены на «вверх» и «вниз». Одна общая кнопка пока не является пользовательской настройкой.

## Приход и уход

| Параметр | Приход | Уход |
|---|---|---|
| Общий период | 08:00–14:00 | 18:00–23:00 |
| Основное окно | 09:00–12:00 | 18:00–20:00 |
| Доля основного окна | 80% | 80% |

Основное окно должно находиться внутри общего. Остальная доля распределяется по доступным минутам до и после него. Влияние раннего прихода на ранний уход — 70%, допустимо 0–100%. Уход раньше прихода запрещён.

## Встречи

| Параметр | По умолчанию | Допустимо |
|---|---:|---:|
| Период встреч | 11:00–19:00 | корректный период суток |
| Среднее число встреч | 3 | 0–10, дробное допустимо |
| Максимум занятых одновременно | 40% | 0–100% |
| Длительности 30/45/60 мин | 30% / 40% / 30% | сумма 100% |
| Доступность переговорной | 80% каждый час | 0–100% для 24 часов |

Используются персональные встречи одного сотрудника. Плановое число посещений равно `round(численность × среднее)`, но фактическое может быть меньше из-за присутствия, пересечений и ограничения одновременной занятости. Конкретные комнаты, вместимость и группы не моделируются. Поиск этажа: 50% — свой, 40% — соседний, 10% — через два этажа, только в физически возможном направлении. Выход назначается ровно за 2 или 3 минуты с равной вероятностью. Опоздание до 5 минут классифицируется как допустимое, но более поздний маршрут также не обрезается и не отменяется.

## Обед

| Параметр | По умолчанию | Допустимо |
|---|---:|---:|
| Период | 13:00–16:00 | корректный период |
| Пик | 14:00 | внутри периода |
| Доля сотрудников | 80% | 0–100% |
| Продолжительность | 30 мин | 15–60, целое |
| Разброс продолжительности | ±15 мин | 0–15, дробное допустимо |
| Ширина волны | 30 мин | 5–120 |

Распределение начала строится по минутам вокруг пика, затем каждому сотруднику назначается секунда 0–59. Интервалы 15/20/30 минут относятся только к отображению графика.

## Лестница

| Параметр | По умолчанию | Допустимо |
|---|---:|---:|
| Время на этаж | 15 с | 1–120 с, шаг 0,1 |
| Лестница удобна | да | да / нет |
| Максимальный добровольный путь | 2 этажа | 1–6, целое |
| Коэффициент неудобной лестницы при обеде | 0,5 | 0–1 |

Обычные вероятности задаются отдельно для 1–6 этажей. Их можно одной кнопкой установить в 0%, полностью отключив добровольный выбор лестницы. При обеденном перегрузе используются семь значений для 1, 2, 3, 4, 5, 6 и 7+ этажей: 0% отключает правило для выбранного расстояния, остальные допустимые значения — от 5 до 100%. Перегруз начинается при очереди не меньше 1,5 вместимости одной кабины.

Зануление добровольных вероятностей и вероятностей при обеденном перегрузе не отключает обязательный участок по лестнице. Если выбранный лифт не останавливается на исходном или целевом этаже, сотрудник всё равно проходит необходимую часть пути пешком.

Значения по умолчанию для удобной лестницы: `90 / 70 / 57,5 / 45 / 32,5 / 20%`; для неудобной: `30 / 10 / 8 / 6 / 4 / 2%`. Для обеденного перегруза: `90 / 70 / 60 / 45 / 30 / 15 / 5%`; правило включено по умолчанию.

## Парковка лифтов по расписанию

Для каждой кабины можно включить интервалы, этаж возврата и паузу без вызовов от 0 до 3600 секунд; по умолчанию правило выключено, пауза равна 60 секундам. При включении нужен минимум один непересекающийся интервал, а этаж должен входить в остановки конкретного лифта. Пассажирский вызов имеет приоритет.

## Результаты и случайность

- Периоды отчёта по умолчанию: утро 08:00–12:00, день 12:00–18:00, вечер 18:00–23:00.
- Пороги долгого ожидания: 120, 240 и 360 секунд; целые, положительные, возрастающие. Счётчик использует строгое условие `ожидание > порог`.
- Номер случайного сценария (`seed`): целое от 0 до 4 294 967 295, по умолчанию 42.
- Изменение номера происходит только по кнопке «Пересоздать поток».
