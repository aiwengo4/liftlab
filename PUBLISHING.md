# Публикация LiftLab

## Выбранная площадка

Основная площадка — GitHub Pages из публичного репозитория `liftlab`. Сайт остаётся статическим: параметры и результаты не отправляются на сервер, расчёт выполняется в Web Worker браузера.

Ожидаемый адрес: `https://<github-login>.github.io/liftlab/`.

## Что уже подготовлено

- `.github/workflows/deploy-pages.yml` запускает тесты и production-сборку;
- Vite получает правильный базовый путь `/liftlab/` из имени репозитория;
- содержимое `dist` публикуется только после успешных тестов;
- повторный выпуск выполняется автоматически после отправки изменений в ветку `main`;
- workflow можно запустить вручную из раздела Actions.

## Однократные действия владельца

1. Создать личный аккаунт на `github.com`; пароль и код двухфакторной аутентификации никому не передавать.
2. Подтвердить адрес электронной почты.
3. Сообщить только публичный GitHub-логин.
4. После загрузки проекта открыть `Settings → Pages` и выбрать `Source: GitHub Actions`, если источник не определился автоматически.

## Контроль после публикации

- открыть основной экран и вкладку «Описание алгоритма»;
- проверить прямую ссылку с `#settings=`;
- выполнить сценарии 4 000/4×10 и 10 000/10×10;
- проверить сохранение в `localStorage` и повторное открытие страницы;
- повторить основную проверку в Chrome и Яндекс Браузере.

## Ограничения

GitHub Pages на бесплатном тарифе требует публичный репозиторий. В репозиторий нельзя добавлять пароли, токены, приватные документы и персональные данные. Текущий проект таких секретов для работы сайта не требует.
