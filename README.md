# LiftLab — симулятор офисных лифтов

Рабочее браузерное приложение для сравнения конфигураций лифтов на одном воспроизводимом потоке сотрудников. Модель считает утренний приход, дневные встречи и обеды, вечерний уход, лестницу, подземный паркинг, очереди и работу каждой кабины.

## Текущий статус

Реализованы форма сценария, расчёт полного дня в Web Worker, три стратегии диспетчеризации, индивидуальные остановки лифтов, подземная парковка сотрудников, парковка кабин по расписанию, результаты по периодам и часам, гистограммы, сохранение до 20 сценариев и сравнение 2–3 вариантов.

Расчёт выполняется в браузере. Серверная часть и установка программ коллегам не нужны.

## Быстрый запуск

```bash
npm ci
npm run dev
```

Production-сборка и проверки:

```bash
npm test
npm run build
```

Тяжёлый performance-прогон запускается отдельно командой `npm run benchmark` и может занимать несколько минут.

## Как пользоваться

1. Откройте вкладку «Расчёт».
2. Укажите численность сотрудников и параметры здания.
3. Настройте лифты, их остановки и потоки рабочего дня.
4. Нажмите «Запустить расчёт».
5. Для честного сравнения меняйте параметры лифтов, не нажимая «Пересоздать поток».
6. Сохраните варианты или передайте коллеге ссылку.

Ссылка использует фрагмент `#settings=` и содержит всю форму, индивидуальные остановки и номер случайного сценария. Она не переносит результаты и библиотеку сохранений: получатель запускает расчёт сам. Сохранённые сценарии хранятся в `localStorage` только текущего браузера.

## Архитектура

```text
App / форма
  → simulation.worker.ts
  → scenarioRunner.ts
  → дискретно-событийное ядро engine/
  → BrowserSimulationResult
  → ResultsView / сравнение сценариев
```

Расчёт изолирован от React и DOM. Одинаковые настройки и номер сценария дают воспроизводимый результат.

## Проверенное поведение

- В ручной приёмке 15 сентября 2026 года Chrome и Яндекс Браузер дали одинаковые отображаемые результаты на одинаковых формах и seed.
- Интерфейс проверен на ширинах 320, 390, 760 и 1440 px.
- Контрольные расчёты: 4 000 сотрудников / 4 лифта — около 4,9 с; 5 000 / 6 — около 6,4 с; 10 000 / 10 — около 14,8 с на машине разработки.
- Эти значения не являются гарантией для другого устройства и другой конфигурации.

## Текущие ограничения

- Лифты считаются исправными весь день.
- Моделируются сотрудники, но не посетители и курьеры.
- Нет анимации реального времени, паузы и ручного управления виртуальными часами.
- Переговорные заданы вероятностью доступности, без конкретных комнат и групповых встреч.
- Пересадки между лифтами не моделируются: используется одна совместимая кабина и, при необходимости, лестница.
